# Varenz Supplies Ltd Website PRD

## One-Liner
Varenz Supplies Ltd needs a premium healthcare supply website that converts product requirements into clear quotation, documentation and delivery follow-up workflows.

## Users
- Hospital procurement teams
- Clinics and medical centres
- Pharmacies
- Diagnostic and imaging centres
- NGOs and healthcare projects
- Research and laboratory programmes
- Internal Varenz sales, operations, records and compliance teams

## Success Looks Like
- A visitor can understand Varenz's supply focus in the first viewport.
- A procurement user can submit a useful request with product, specification, quantity and timeline details.
- Navigation links land on real sections or open the correct action.
- Team QR profile routes remain stable.
- Product cards communicate "available on enquiry" and "specifications confirmed at request" without unsupported medical claims.
- Every future upgrade uses the documented section framework instead of replacing it.

## In Scope
- Preserve the MVC PHP structure and one-page section framework.
- Improve header links, official contact details, SEO metadata and customer-facing copy.
- Add a request-quality assistant that improves submissions without requiring an external AI API.
- Add design tokens and clinical brochure-style CSS enhancements.
- Maintain reduced-motion and mobile responsiveness.

## Out Of Scope
- Replacing the site with a new framework.
- Removing functioning sliders, modals, forms, search or team profile routes.
- Publishing unsupported regulatory or medical claims.
- Adding paid API dependencies without a credential and approval workflow.

## Primary Conversion Path
1. Visitor sees a relevant product/service promise.
2. Visitor explores products, procurement steps or organisation support.
3. Visitor opens the request form.
4. Request assistant helps them add product, specification, quantity and timeline details.
5. Form returns a reference number for follow-up.
